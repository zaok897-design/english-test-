1

Шалгалтаа сонгох

«Шалгалт өгөх» товчийг дарж, жил (2021–2025) болон хувилбар (A эсвэл B)-аа сонгоно.

2

Мэдээллээ бөглөх

Овог нэр, ангиа зөв бичнэ үү. Энэ мэдээлэл үр дүнтэй хамт хадгалагдана.

3

Асуултад хариулах

Асуулт бүрт нэг зөв хариултыг сонгоно. Баруун талын дугааруудыг ашиглан асуулт хооронд шилжиж болно.

4

Шалгалтаа дуусгах

«Шалгалтыг дуусгах» товчийг дарж баталгаажуулна. Хугацаа дуусахад автоматаар илгээгдэнэ.

5

Үр дүнгээ харах

Оноо, хувь, дүн болон алдсан асуултуудын зөв хариултыг шууд харна.

⚙️ Google Sheets холболтын тохиргоо

Үр дүнг автоматаар Google Sheets рүү илгээхийн тулд Google Apps Script Web App-ийн URL-ийг оруулна уу. URL-ийг энэ хөтөч дээр хадгална.

Google Apps Script код (Code.gs):

function doPost(e) {
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName('Results') || ss.insertSheet('Results');

    if (sheet.getLastRow() === 0) {
      sheet.appendRow(['Огноо','Овог нэр','Анги','Жил','Хувилбар',
                       'Оноо','Нийт','Хувь','Дүн','Хугацаа']);
    }

    var d = JSON.parse(e.postData.contents);
    sheet.appendRow([
      new Date(),
      d.name,
      d.className,
      d.year,
      d.version,
      d.score,
      d.total,
      d.percent + '%',
      d.grade,
      d.timeUsed
    ]);

    return ContentService
      .createTextOutput(JSON.stringify({ status: 'ok' }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'error', message: err.message }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
